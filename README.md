### Цель работы
Провести тестирование разработанных программных модулей с использованием средств автоматизации Microsoft Visual Studio методом «белого ящика».
# Описание проекта
Было создано консольное приложение Bank, содержащее класс BankAccount, который реализует работу банковского счета.
Класс поддерживает следующие операции:
- Debit — снятие денежных средств со счета
- Credit — зачисление денежных средств на счет
Для тестирования приложения был создан отдельный проект BankTests, содержащий модульные тесты
# Документирование кода
Для документирования программного кода использовались XML-комментарии языка C#.
Основные используемые теги:
- summary — описание класса или метода  
- param — описание параметров  
- returns — описание возвращаемого значения  
- exception — описание возможных исключений  
# Созданные модульные тесты
В тестовом проекте были реализованы тесты для методов Debit и Credit.
### Тесты метода Debit
1. Debit_WithValidAmount_UpdatesBalance  
Проверяет, что баланс счета уменьшается на сумму списания.
2. Debit_WhenAmountIsLessThanZero_ShouldThrowArgumentOutOfRange  
Проверяет, что метод выбрасывает исключение ArgumentOutOfRangeException при отрицательной сумме.
3. Debit_WhenAmountIsMoreThanBalance_ShouldThrowArgumentOutOfRange  
Проверяет, что метод выбрасывает исключение, если сумма списания превышает баланс.
### Тесты метода Credit
4. Credit_WithValidAmount_IncreasesBalance  
Проверяет, что баланс увеличивается на сумму зачисления.
5. Credit_WhenAmountIsLessThanZero_ShouldThrowArgumentOutOfRange  
Проверяет, что при отрицательной сумме выбрасывается исключение ArgumentOutOfRangeException.
# Обнаруженная ошибка
При первом запуске тестов было обнаружено, что метод Debit работает некорректно.
Ошибка заключалась в следующей строке кода:
m_balance += amount;
Вместо вычитания сумма списания добавлялась к балансу.
Исправление:
m_balance -= amount;
После исправления ошибки все тесты были успешно выполнены.
